# Парсер метрик Холстеда для PHP

Проект выполнен для практического задания №1 по дисциплине «Стандартизация программного обеспечения». Программа анализирует исходный код на PHP, выводит таблицу операторов и операндов и рассчитывает шесть базовых и три производные метрики Холстеда.

## Что входит в проект

- `public/index.php` — графический веб-интерфейс;
- `public/styles.css` — оформление страницы;
- `src/HalsteadAnalyzer.php` — лексический анализ и расчёт метрик;
- `src/InputValidator.php` — безопасная обработка формы и загруженных файлов;
- `sample/analyzed_program.php` — консольная программа на PHP объёмом 96 строк;
- `tests/run.php` — модульные тесты;
- `tests/http_smoke.sh` — проверка веб-интерфейса;
- `tools/export_result.php` — экспорт результатов примера в JSON;
- `report/Отчет_Задание_1_Метрики_Холстеда.docx` — отчёт для печати.

## Требования

- PHP 8.1 или новее;
- любой современный браузер;
- база данных и Composer не требуются.

## Как запустить

1. Откройте терминал в папке проекта.
2. Запустите локальный сервер:

```bash
php -S localhost:8000 -t public
```

3. Откройте в браузере адрес `http://localhost:8000`.
4. Вставьте PHP-код или выберите файл `.php` размером не более 1 МиБ.
5. Нажмите «Рассчитать метрики».

Кнопка «Загрузить пример» подставляет и сразу анализирует файл `sample/analyzed_program.php`. Загруженный код разбирается на токены, но никогда не выполняется.

## Какие данные выводятся

### Базовые метрики

- `η₁` — количество уникальных операторов;
- `η₂` — количество уникальных операндов;
- `N₁` — общее количество операторов;
- `N₂` — общее количество операндов;
- `f1j` — частота вхождения каждого оператора;
- `f2i` — частота вхождения каждого операнда.

### Производные метрики

- словарь программы: `η = η₁ + η₂`;
- длина программы: `N = N₁ + N₂`;
- объём программы: `V = N × log₂(η)`.

Для приложенного примера получены следующие значения:

| Метрика | Значение |
|---|---:|
| `η₁` | 55 |
| `η₂` | 68 |
| `N₁` | 268 |
| `N₂` | 180 |
| `η` | 123 |
| `N` | 448 |
| `V` | 3110,25 бит |

## Правила распознавания PHP

Парсер использует штатную функцию PHP `token_get_all()` с флагом `TOKEN_PARSE`. Благодаря этому комментарии и пробелы исключаются на уровне лексического анализатора, а синтаксически ошибочный код не выдаёт ложный результат.

Операторами считаются:

- арифметические, сравнительные, логические и побитовые операции;
- операции присваивания, конкатенация, инкремент и декремент;
- `if`, `elseif`, `else`, `switch`, `case`, `match`;
- `for`, `foreach`, `while`, `do`, `break`, `continue`;
- `function`, `return`, `try`, `catch`, `finally`, `throw`;
- другие использованные ключевые слова PHP;
- имена вызываемых функций в форме `имя()`;
- точка с запятой, запятая, двоеточие и парные разделители `()`, `[]`, `{}`.

Круглые скобки, входящие в вызов функции или управляющую конструкцию, отдельно не дублируются: вызов `count($items)` учитывается как оператор `count()`. Круглые скобки самостоятельной группировки выражения учитываются как `()`.

Операндами считаются:

- переменные;
- числовые и строковые литералы;
- значения `true`, `false` и `null`;
- константы и идентификаторы, используемые как значения.

Имена объявляемых функций, встроенные типы и служебные элементы не записываются в таблицу операндов.

## Анализируемая программа

Файл `sample/analyzed_program.php` является консольным приложением на 96 строк. В нём есть:

- пользовательские функции с параметрами и возвращаемыми значениями;
- арифметические, сравнительные, логические операции и присваивания;
- `if / elseif / else`, `switch`, `match`, тернарный оператор;
- `for`, `foreach`, `while`, `do...while`;
- `break`, `continue`, `try / catch`;
- массивы и консольный ввод-вывод.

Запуск примера:

```bash
php sample/analyzed_program.php
```
